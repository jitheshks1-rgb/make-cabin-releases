# Make Cabin Factory

Cabinet design, drafting, cutting lists and costing for SketchUp.

## Download

Go to **[Latest release](https://github.com/jitheshks1-rgb/make-cabin-releases/releases/latest)** and download the file ending in **.rbz** (under *Assets*).

## Install

1. Open **SketchUp 2026**.
2. Go to **Extensions → Extension Manager**.
3. Click **Install Extension** and choose the downloaded **.rbz** file.
4. Click **Yes**, then restart SketchUp.
5. The **Activate Make Cabin Factory** window opens. Type your **firm name** and **licence key** exactly as you received them, then click **Activate**.
   The first connection of the day can take up to a minute.

## Update

When a new version is out, SketchUp tells you. You can also check any time:
**Extensions → Make Cabin → Check for Updates**.
Download the new **.rbz** and install it the same way. Your licence, firm logo and settings stay as they are.

## Help

- **Licence details and sheets left:** Extensions → Make Cabin → Make Cabin Licence…
- **"Please connect to the internet":** connect this computer to the internet and click Activate again. Your models are safe.
- **New or reinstalled computer:** each licence key works on one computer. Please contact Make Cabin for a new key.
